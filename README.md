
# LaporKerma – Sistem Pelaporan Kerja Sama Kemendiktisaintek

Repository ini berisi source code hasil pengembangan website **Sistem Pelaporan Kerja Sama (LaporKerma)** milik Kementerian Pendidikan Tinggi, Sains, dan Teknologi (Kemendiktisaintek).

Proyek ini dikembangkan sebagai bagian dari penelitian Tugas Akhir (Skripsi) Program Studi Teknik Informatika, Universitas Bakrie, dengan judul:

**"Rancang Bangun dan Evaluasi Performa Website Sistem Pelaporan Kerjasama (Laporkerma) Kemendiktisaintek Berbasis Laravel Menggunakan Google Lighthouse".**

Pengembangan dilakukan dengan membangun ulang halaman publik website LaporKerma dari sistem sebelumnya yang menggunakan CodeIgniter menjadi aplikasi berbasis **Laravel 12**. Fokus pengembangan meliputi pembaruan antarmuka, pengelolaan dan penyajian informasi kerja sama, serta evaluasi performa website.

## 🚀 Fitur yang Dikembangkan

- **Home Page:** Menampilkan informasi umum dan statistik kerja sama perguruan tinggi berdasarkan kategori Memorandum of Understanding (MoU), Memorandum of Agreement (MoA), dan Implementation Arrangement (IA).
- **Spasial:** Menampilkan visualisasi persebaran kerja sama perguruan tinggi berdasarkan negara menggunakan peta interaktif.
- **Informasi Spasial:** Menyediakan informasi detail lokasi dan jumlah kerja sama pada setiap negara.

## 🛠️ Teknologi yang Digunakan

- PHP 8.2
- Laravel 12
- MySQL
- HTML5 & CSS3
- JavaScript
- Blade Template Engine
- Leaflet.js
- Google Lighthouse

## 📊 Pengujian dan Evaluasi Performa

Evaluasi dilakukan untuk membandingkan performa website sebelum dan sesudah pengembangan menggunakan Google Lighthouse.

Metrik pengujian meliputi:

- Performance Score
- First Contentful Paint (FCP)
- Largest Contentful Paint (LCP)
- Total Blocking Time (TBT)
- Cumulative Layout Shift (CLS)

Pengujian dilakukan sebanyak lima kali pengulangan selama tujuh hari untuk memperoleh hasil evaluasi performa yang lebih representatif.

## 📌 Ruang Lingkup

Pengembangan difokuskan pada dua halaman publik utama:

1. Halaman Home
2. Halaman Spasial

Penelitian ini tidak mencakup pengembangan halaman login, autentikasi, maupun administrasi sistem.
